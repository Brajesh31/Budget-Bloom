# Support

## Where to ask

- For reproducible bugs or focused feature proposals, open an issue in the [GitHub repository](https://github.com/Brajesh31/Budget-Bloom/issues).
- For setup questions, see [Installation](docs/installation.md) and [Troubleshooting](docs/troubleshooting.md).
- For suspected vulnerabilities or exposed credentials, follow [SECURITY.md](SECURITY.md) and report privately.
- For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and contact the maintainer through [@brajesh31](https://github.com/brajesh31).

## Include in a useful issue

Describe what you expected, what happened, reproduction steps, browser and Node.js versions, relevant terminal output, and the route or component involved. Remove connection strings, session tokens, private financial information, and personal data before sharing logs or screenshots.

## Project scope

This is an individual application prototype, not a financial advisory service or a supported production product. It has no uptime or response-time commitment. Do not use it to store real financial data until the database credentials and server-side authorization issues documented in [Security](SECURITY.md) are fixed.
